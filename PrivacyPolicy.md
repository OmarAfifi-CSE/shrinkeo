# Privacy Policy

**Effective Date:** June 2026

Welcome to Shrinkeo! Your privacy is critically important to me. This Privacy Policy outlines how your data is handled when you use the Shrinkeo desktop application.

## 1. Local Processing
Shrinkeo is an offline desktop application designed to run entirely on your local machine. All video compression, processing, and file handling happen strictly on your local device. 

## 2. No Data Collection
I do not collect, store, transmit, or share any personal information, telemetry data, analytics, or video files with any external servers or third parties. 

## 3. FFmpeg Usage
Shrinkeo utilizes the open-source FFmpeg software for video compression. FFmpeg runs locally within the application and does not communicate with external servers.

## 4. Permissions
Shrinkeo requires local read and write permissions on your device to access the videos you choose to compress and to save the output files. The application's Windows Explorer context menu integration requires administrative privileges during installation to register the necessary local registry keys.

## 5. Changes to This Policy
If I make any significant changes to how Shrinkeo operates regarding user privacy, I will update this policy accordingly.

## 6. Contact Me
If you have any questions or concerns about this Privacy Policy or the Shrinkeo application, please open an issue on the official GitHub repository.
